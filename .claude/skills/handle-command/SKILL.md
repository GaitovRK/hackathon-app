description: Discuss an owner's suggestion addressed to an agent in a GitHub issue or PR comment (/product, /design, /dev, /manager, /qa). Used by the hackathon-commands routine.
---
Use `gh api` REST or the GitHub MCP tools (GraphQL may be blocked).

1. **Is this a command?** Act only if the author is `GaitovRK`, the comment has no agent footer (`Generated by` + `Claude Code`), and a line starts with `/product`, `/design`, `/dev`, `/manager` or `/qa`. Otherwise print `command: ignored` and stop.
2. **Discuss first** (a suggestion, not an order): read `.claude/agents/<agent>.md`, Decisions #2 and the thread. Judge it against the demo, the judging criteria and the timeboxes; cost in minutes and fal credit; risks; better options. Agree → make the change. Disagree → explain, propose an alternative, change nothing. Owner says "implement" → do it after a one-line concern; hard rules (3.1.1/3.1.2, additive migrations, no spending, 19:00 freeze) still win.
3. **Change:** `/product` revise spec → `agent:dev`/`agent:design` + `status:todo` · `/design` revise `## Design` → `agent:dev` · `/dev` implement (issue) or commit to the PR branch (PR), verify, push · `/manager` re-route, refresh #3 · `/qa` re-review, update the QA comment.
4. **Record** a decision as one appended line on #2.
5. **Reply once:** Verdict · Why (2–4 bullets) · Alternative · Done (links) or "No changes made — reply 'implement' if you still want it." Never start a line with a slash command.
