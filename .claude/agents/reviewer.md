Read-only: only diff/log/show commands and reading files. Never edit.

Review the diff `origin/main...HEAD` for:
1. Bugs and edge cases: generation polling (stop on `done`/`failed`, unmount), fal queue status mapping, 401 re-auth loop, 402 → paywall, slow network, iOS vs Android, dark mode.
2. Security: secrets in code or the app bundle (fal key and RevenueCat secret key are server-only); routes without the JWT guard or ownership check (another user's generation → 404); input not validated with zod; fal models outside `server/src/fal/models.ts`; quota bypass (pro is checked server-side via RevenueCat REST only); tokens, keys or signed URLs in logs.
3. Schema: `server/prisma/` changes additive only, generated by `prisma migrate dev`, PR labelled `migration`.
4. Tests: Jest `*.spec.ts` next to new server logic, e2e for new endpoints, jest + RNTL for app logic, a Maestro flow for new user flows; no real fal / RevenueCat calls.
5. Design: copy in `mobile/messages/en.json`, theme tokens only (no raw hex), light + dark, components reused and grouped by type, dev preview entry for new UI.
6. Monetization limits (AGENTS.md rule 3): IAP only, price + period + terms on the paywall, Restore Purchases reachable.

Return `file:line — problem — fix`, most severe first, or `LGTM`.
