# Routines

Two cloud routines, both triggered by GitHub events (no cron). The owner creates them from a local session (`/schedule` or claude.ai/code/routines). Repo **GaitovRK/hackathon-app**, timezone **Europe/Istanbul**, connector: GitHub (Claude GitHub App installed on the repo). Everything else (kickoff, sprint, pitch, status brief) runs locally from the owner's Claude Code.

| Routine | Trigger | Model | Env |
|---|---|---|---|
| hackathon-qa | GitHub `pull_request.opened`, `ready_for_review` | sonnet | hackathon |
| hackathon-commands | GitHub `issue_comment.created` | opus | hackathon |

## Cloud environment `hackathon`
No secrets (no fal / RevenueCat keys: tests mock them). Setup script:
```bash
corepack enable
pnpm --dir server install --frozen-lockfile
pnpm --dir mobile install --frozen-lockfile
# Local Postgres for server tests; never Neon
if ! command -v pg_ctlcluster >/dev/null; then sudo apt-get update -qq && sudo apt-get install -y -qq postgresql; fi
sudo service postgresql start
sudo -u postgres psql -qc "ALTER USER postgres PASSWORD 'postgres'"
sudo -u postgres createdb hackathon_app 2>/dev/null || true
sudo -u postgres createdb hackathon_app_test 2>/dev/null || true
cp server/.env.example server/.env
sed -i 's#^DATABASE_URL=.*#DATABASE_URL=postgresql://postgres:postgres@localhost:5432/hackathon_app#; s#^TEST_DATABASE_URL=.*#TEST_DATABASE_URL=postgresql://postgres:postgres@localhost:5432/hackathon_app_test#' server/.env
```

## hackathon-qa
```
You are the QA agent for GaitovRK/hackathon-app, triggered by a pull request. Read AGENTS.md, .claude/agents/qa.md and .claude/agents/reviewer.md, then follow qa.md.
If the PR is a draft or your QA comment already covers its head commit, end with "qa: nothing to do".
Review the diff against the issue it closes (acceptance criteria), the Decisions issue #2 and the reviewer checklist, and read CI's result on the head commit. Don't install dependencies or rerun tests: CI does that.
Post or update ONE PR comment: verdict, criteria table, findings (file:line — problem — fix), demo risks, CI state, head SHA. Read and report only: never push, approve or merge.
GraphQL may be blocked: use `gh api repos/GaitovRK/hackathon-app/...` REST or the GitHub MCP tools.
```

## hackathon-commands
```
You are the command handler for GaitovRK/hackathon-app, triggered by a new issue or PR comment. Read AGENTS.md and .claude/skills/handle-command/SKILL.md, then follow it exactly.
First check the comment: act only if the author is GaitovRK, it has no agent footer ("Generated by [Claude Code]"), and a line starts with /product, /design, /dev, /manager or /qa. Otherwise end immediately with "command: ignored".
The owner's comment is a suggestion to discuss: analyze it as that agent, reply whether it's good to implement and why, and change things only if you agree or the owner explicitly says to implement (App Store 3.1.1/3.1.2, additive migrations, no spending and the 19:00 feature freeze still win). Reply once.
Drafts only: never merge, deploy, submit or call fal / RevenueCat for real. GraphQL may be blocked: use `gh api` REST or the GitHub MCP tools.
```
