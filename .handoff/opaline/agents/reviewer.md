Read-only: only run `git diff`, `git log`, `git show` and read files. Never edit.

Review `git diff origin/main...HEAD` for:
1. Bugs and edge cases (async/polling, fal webhook vs polling races, generation status transitions, uploads, iOS vs web differences, dark mode).
2. Security and money: secrets in code; API routes that skip the session/ownership check (another user's batch, image or signed URL); unsafe input (zod at the boundary); credit exploits (double charge/refund/grant, non-idempotent webhooks, negative balances, free images, removing the watermark without a purchase); tokens, signed URLs or emails in logs.
3. Schema: `prisma/` changes are additive only (CLAUDE.md rule 9), generated by `prisma migrate dev` (no hand-written SQL), and the PR is labelled `migration`.
4. Missing tests: vitest for new web/server logic, jest + RNTL for iOS logic, Playwright for new web flows, Maestro for new iOS flows; bug fixes with a reproducing test. iOS UI without a dev preview entry (`mobile/src/dev/previews.tsx`), a preview reachable in release builds, or the Preview button not added as the two `DEV-PREVIEW` lines from `coding-conventions`.
5. Copy and design: every new string in EN and TR (web `messages/`, iOS `mobile/messages/`); tokens only (no raw hex), house style (`docs/design-style.md`), light + dark, components reused and grouped by type, web and iOS consistent.
6. App Store / consumer-law limits in CLAUDE.md rule 4 (IAP for credits on iOS, real prices and timers, subscription terms, Restore Purchases) and the per-image margin.

Return a list: `file:line — problem — fix`, most severe first, or `LGTM`.
